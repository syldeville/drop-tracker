DROPS - HOW TO USE


INSTALL ON YOUR IPHONE

1. Open https://syldeville.github.io/drop-tracker/ in Safari.
2. Tap Share, then Add to Home Screen.
3. Always open Drops from the home screen icon. Notifications only work there.


TURN ON NOTIFICATIONS (one time)

The daily check runs on GitHub, not on your phone. GitHub needs your
phone's notification address (the "setup code") to know where to send them.

1. On your iPhone, open Drops, go to the Settings tab, tap Turn On Notifications,
   and allow them.
2. Tap Copy Setup Code. Do this on the phone, not your computer.
3. On GitHub, open the drop-tracker repo, then
   Settings > Secrets and variables > Actions > New repository secret.
4. Name: PUSH_SUBSCRIPTION    Value: paste the setup code. Save.
5. Add a second secret.
   Name: VAPID_PRIVATE        Value: the private key you were given at setup.
   Never put this key in a file in the repo.
6. Test it: Actions > Check drops > Run workflow.

Redo steps 1-4 if you delete and re-add the app or change phones.


WHEN IT CHECKS

Automatically every day at 08:00 UTC (9am UK summer, 8am winter).
Nothing to run by hand. To check right now: Actions > Check drops > Run workflow.

If the check fails at the push step:
Settings > Actions > General > Workflow permissions > Read and write.


USING THE APP

Feed      Everything new from the brands you follow in one list, newest first:
          shop drops, Vinted and eBay mixed together. Each photo is labelled
          with where it's from. Tap the menu button (three lines, top left)
          to filter by where it's listed (Main site, Vinted, eBay) and by
          brand. Pick as many as you like. A dot on the menu button means
          filters are on; Clear shows everything again.
          Tap any item to open it. Tap Feed again to jump to the top.
Brands    Switch brands on or off. Your choice is saved on your phone and only
          changes what the Feed shows. Notifications still cover every brand.
Settings  Notifications, when it last checked, and any brand it couldn't check.


ADDING A BRAND

Edit check.mjs on GitHub and add a line to the BRANDS list.
Most indie brands: if theirsite.com/products.json shows product text, use
  { name: 'Brand Name', shopify: 'https://theirsite.com', vinted: 12345 },
The vinted number is in the brand's Vinted page address, e.g.
vinted.co.uk/brand/1042718-lucy-yak is 1042718.
It appears in the Brands tab after the next check. The first check after adding only records what's already there. Only items
added after that count as new.


RUNNING ON YOUR COMPUTER (optional, for testing)

  npm install
  node check.mjs
  python3 -m http.server 8000     then open http://localhost:8000

Afterwards undo the test data so the daily check still notifies you:
  git checkout drops.json seen.json
